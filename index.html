Featured — Academic Platform

G Class Advance

A classroom management platform with distinct teacher and student experiences — dashboards, courses, assignments, grades, attendance, and timetables, with role-based access control. An ongoing independent build, not a finished product.

Challenge: keeping two very different user roles (teacher, student) cleanly separated in the same codebase while sharing a single Firestore data model.
Approach: role-based routing and access rules on top of Firebase Auth, with Firestore collections structured around courses rather than roles.

IoT Prototype

Thermal Server Watchdog

An IoT cube that monitors temperature and humidity around a server or equipment rack, shows live status on an OLED display, and pushes remote alerts over Wi-Fi.

Challenge: getting a Pico, an ESP8266, a DHT11 sensor, and an SSD1306 OLED to talk reliably over I2C/UART without a reliable power supply.
Approach: isolated sensor polling from display refresh, and offloaded notifications to ntfy over Wi-Fi instead of running a server on-device.

  • Raspberry Pi Pico
  • ESP8266
  • DHT11
  • SSD1306 OLED
  • Arduino/C++

Thermal Server Watchdog

A Raspberry Pi Pico reads temperature and humidity from a DHT11 sensor and drives a 128×64 SSD1306 OLED over I2C to show live status. An ESP8266 handles Wi-Fi connectivity and sends alert notifications through ntfy when thresholds are crossed. A relay allows basic automated response to overheating conditions.

This is a working prototype built for learning embedded systems and network communication — not a deployed production monitoring system.
